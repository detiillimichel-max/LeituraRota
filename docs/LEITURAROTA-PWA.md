## Requisitos do futuro PWA

- Selecionar qualquer uma das 20 rotas.
- Mostrar ruas na ordem cadastrada.
- Mostrar progresso concluídos/total.
- Desenhar a geometria da rota no mapa.
- Mostrar localização atual.
- Registrar leituras sem perder dados.
- Operar com conexão fraca e, idealmente, offline-first.
- Usar IndexedDB para dados de campo e Service Worker/Cache Storage para recursos.
- Sincronizar registros pendentes quando a conexão retornar.
- Manter última rota e progresso local.
